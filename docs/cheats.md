# Cheats

Use **Launcher → Settings → Cheats** or press **F9** in game. F7 opens achievements.

## Hyperspeed

| Setting | Highway scroll speed |
| --- | --- |
| Off | Normal |
| Level 1 | 1.50×, original GH2 Hyperspeed |
| Level 2 | 1.75× |
| Level 3 | 2.00× |
| Level 4 | 2.25× |
| Level 5 | 2.50× |

Choose a level before loading a song or Practice session. Hyperspeed changes highway scrolling, not music speed or note timing. A song already loaded keeps its current setting.

## Other cheats

Air Guitar, Performance Mode, Flaming Head, Eyeball/Monkey Crowd Heads and Unlock All are available. Performance Mode hides the highway.

**Original cheat codes** keeps the setting selected through the game's fret codes. Choose On or Off to override it, and save to remember your preference.

**Unlock All** makes the song list available but disables career and saving while enabled. If changing it outside the main menu, return there to refresh the song list. Turn it off to restore normal progression and saving.
