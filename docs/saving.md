# Saves and settings

Saves are stored under `Documents\GH2PC\Saves`. PC preferences are stored in `Documents\GH2PC\gh2.toml`. Redirected and OneDrive Documents folders are supported.

The game manages the files inside Saves. There is no need to choose a Windows folder from the game's storage menu. If a storage prompt appears, its local storage device writes to the same Documents location. Choosing **Continue without saving** disables saving for that session.

## Local profile

The original **Sign in** prompt refers to the game's local profile. A Microsoft account is not required. If you start with a different controller, accepting Sign in associates the offline profile with that controller. Saves remain in the same folder. Separate player profiles are not available.

## Manage saves

Open **Launcher → Settings → Saves** to export, import or delete saves. Previous saves are retained in `Documents\GH2PC\Save Backups`. Close the game normally before changing saves, and keep an exported backup before importing another copy.

Source updates retain Documents saves and settings. **Unlock All** disables career and saving while enabled; turn it off for normal progression.
