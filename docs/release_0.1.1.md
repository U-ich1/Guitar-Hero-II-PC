## Changes in 0.1.1

- Added **Guitar Hero 2 Updater.exe** as a separate graphical application.
- Selects the latest GitHub release by default, with a version picker and optional preview releases.
- Downloads and verifies source packages, then rebuilds using the existing game dump.
- Shows release notes, download progress, build output and an update log.
- Adds download cancellation and checks for a running game or launcher before installation.
- Records an installed version only after a completed build.
- Retires unchanged source files removed from newer releases, with backups; keeps locally edited files.
- Prevents the launcher from starting the game while an update is being built.
- Updates the launcher version to **0.1.1** without adding updater controls to its layout.
- Includes the refreshed README and practical feature guides.
