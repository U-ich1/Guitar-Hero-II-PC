# Guitar Hero 2 Launcher

Open **Guitar Hero 2 Launcher.exe** in your built project folder. The home screen offers Play, Settings and Exit. Keep it beside the `tools`, `private` and `build` folders.

## Settings

- **Graphics:** resolution, anti-aliasing, filtering, display mode, monitor, VSync, FPS limit, audience visibility and Discord Rich Presence. Hover over setting titles for help.
- **Controls:** choose XInput or DirectInput, select a named device and configure separate guitar and gamepad mappings.
- **Calibration:** audio delay, buffering and mute. Video calibration is available in the game's Options menu.
- **Cheats:** Hyperspeed levels 1–5 and the original game cheats.
- **Saves:** import, export and delete saves, with backups.

Click a controller mapping, then press the button you want to use. Release any held buttons before capture. Escape cancels capture; right-click clears a mapping. Select a specific device to capture only its inputs.

**Save settings** keeps your changes. **Reload settings** reads the current saved values. **Play** saves settings, starts the game and closes the launcher. If the game cannot start, the launcher stays open and displays an error.

Save and Play are disabled while the game is running. Use the in-game panels for live changes, or close the game normally before saving from the launcher. Closing the launcher does not close the game.

Settings are shared with the game in `Documents\GH2PC\gh2.toml`. See [controls](controls.md), [graphics](graphics_settings.md) and [saving](saving.md) for more help.
