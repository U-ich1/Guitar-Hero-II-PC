# Audio calibration

Use **Launcher → Settings → Calibration** to set added audio delay. Press **F8** in game for the flash/click reference. Pause a song before using the reference.

- Delay ranges from 0 to 250 ms. Zero adds no delay; positive values play sound later.
- Use the 5 ms buttons for small adjustments, then save.
- Change delay between songs, since an adjustment can briefly interrupt audio.
- **Lower audio buffering** can reduce delay but may cause audio stutters. Save and restart to apply it.

The flash/click reference is approximate. Check the result in Practice with your normal audio equipment. Added delay cannot bring already-late audio forward; start at zero and try lower buffering in that case.

Video calibration is available under **Options → Calibrate Lag** in the game. A separate launcher video-calibration tool is planned.

Settings are shared with the game in `Documents\GH2PC\gh2.toml`.
